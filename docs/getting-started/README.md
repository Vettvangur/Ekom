# Getting started

[Ekom docs](../README.md) / Getting started

This section takes you from an Umbraco site without Ekom to a site where your own code adds a product to a basket. It is for developers who install Ekom on an Umbraco 17, 18 or 19 site.

You need a working Umbraco site and access to its web project. You do not need to build Ekom from source.

## Follow the steps in order

Each page ends with a link to the next one.

1. [Compatibility](compatibility.md): find the two packages that match your Umbraco version.
2. [Installation](installation.md): add the packages, start the site and check that Ekom is running.
3. [Configuration](configuration.md): set the `Ekom` settings your site needs.
4. [Quick start](quick-start.md): create a store and a product, then add the product to a basket from code.
