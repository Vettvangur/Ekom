# Contributing

This section is for people who work on Ekom itself: change its source, run its tests and release new versions. If you install Ekom on a site and build a store with it, you do not need this section; start with [Getting started](../getting-started/README.md).

## Where to start

1. [Set up a development environment](setup.md): install the tools, build the solutions and run a sample site.
2. [Build, test and release](build-test-release.md): run the tests, check a package, and follow the release process.

## Pages in this section

| Page | Read it when you want to |
| --- | --- |
| [Set up a development environment](setup.md) | Install the SDKs and Node.js, choose a solution, work on a plugin against local Ekom code, or run a sample site. |
| [Build, test and release](build-test-release.md) | Run tests, check a package before release, write a pull request title, or release a hotfix. |
