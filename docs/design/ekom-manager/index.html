Ekom for Umbraco 17

Ekom Manager

Orders, Analytics, Customers and Printing behind one section switch and one shared filter (store, status, date range). Orders uses Shopify-style views and separate Order / Payment / Fulfillment statuses; the order panel slides in over the list with Summary, Lines, Customer, Payment, Shipping, Tracking and Activity log tabs. All colours come from one token set, switched by the Theme tweak to match Umbraco's light and dark skins.
