# Discounts and coupons

Ekom has two main discount types: **product discounts**, which reduce product prices, and **order discounts**, which apply an offer to eligible basket items. An order discount can be automatic or activated by a coupon code.

Choose the guide for your work:

| Audience | Start here |
| --- | --- |
| Store editors | [Configure discounts in Umbraco](discounts/editors.md): choose an offer, understand the fields, and test the result. |
| Developers | [Discount APIs and behavior](discounts/developers.md): apply coupons, extend eligibility, and integrate with calculations and stock. |

## Editor guides

- [Product discounts](discounts/product-discounts.md) — put products or categories on sale, exclude items, or set a target selling price.
- [Order discounts](discounts/order-discounts.md) — configure automatic offers, quantity rules, and interaction with existing product discounts.
- [Coupons](discounts/coupons.md) — create codes, generate batches, and understand usage limits.

> **Coupon usage limits apply to the code, not to the customer.** A limit of 1 means the code can be used once overall, not once per customer. Limits are not based on customer identity or login. See [coupon usage limits](discounts/coupons.md#understand-usage-limits).
